👨‍💻 Sobre mim
Sou Gabriel Fila, estudante de Ciência da Computação na Universidade Positivo, em Curitiba. Ao longo da graduação, venho aprofundando meu interesse em análise de dados, desenvolvimento back-end e bancos de dados, com o objetivo de construir uma carreira na área de tecnologia.
Além das disciplinas da faculdade, desenvolvo projetos pessoais de programação voltados para web, que me ajudam a praticar lógica, desenvolvimento de software e resolução de problemas de forma independente.
Também tenho curiosidade por hardware e pelo funcionamento dos sistemas computacionais, desde os componentes físicos até o processamento e a análise dos dados.
🎯 Objetivo profissional
Meu objetivo é atuar profissionalmente na área de análise de dados, aplicando conhecimentos de bancos de dados, back-end e desenvolvimento de sistemas. Busco unir formação acadêmica, prática constante de programação e desenvolvimento contínuo de competências técnicas.
🔍 Áreas de interesse
Análise de dados: processamento, interpretação e exploração de informações.
Desenvolvimento back-end: lógica de aplicações e funcionamento dos sistemas.
Bancos de dados: armazenamento, organização e consulta de informações.
Desenvolvimento de software: criação e evolução de soluções computacionais.
Hardware: compreensão dos componentes e do funcionamento das máquinas.
